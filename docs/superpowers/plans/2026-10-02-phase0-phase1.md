# Phase 0 · Phase 1 구현 계획 (프로젝트 골격 + Core 도메인)

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `uv` 기반 src 레이아웃 패키지를 만들고, CLI/Web이 공통으로 쓰는 `logbook.core`(duration, weeks, config, models, db, services)를 테스트와 함께 완성한다.

**Architecture:** `core`는 CLI/Web에 의존하지 않는 순수 도메인 계층이다. 서비스 함수는 SQLAlchemy `Session`을 첫 인자로 받고, 시간은 정수 분, 날짜는 `date`, 타임스탬프는 UTC-aware `datetime`으로 다룬다. 모든 사용자 대면 오류는 `LogbookError` 계열 예외에 한국어 메시지를 담아 던지고, CLI/Web 레이어가 이를 출력한다.

**Tech Stack:** Python 3.11+, uv, SQLAlchemy 2.0 (`Mapped[]`), Typer, Rich, tomllib/tomli-w, pytest, ruff, mypy(strict: core만)

**선행 조건:** 이 PC에 `uv`가 없다. `pip install --user uv` 또는 `winget install astral-sh.uv`로 설치 후 시작한다.

### Task 1-3: weeks.py

**Files:** `src/logbook/core/weeks.py`, `tests/core/test_weeks.py`

```python
WeekStart = Literal["monday", "sunday"]

@dataclass(frozen=True, order=True)
class Week:
    year: int
    number: int
    week_start: WeekStart = "monday"
    @property
    def label(self) -> str          # "2026-W40"
    @property
    def start(self) -> date         # ISO 월요일, sunday 모드면 하루 앞
    @property
    def end(self) -> date           # start + 6
    def contains(self, d: date) -> bool
    def next(self) -> Week
    def prev(self) -> Week
    def days(self) -> list[date]    # 7일

def week_of(d: date, week_start: WeekStart = "monday") -> Week
def parse_week(text: str, *, today: date | None = None, week_start: WeekStart = "monday") -> Week
    # "this" | "last" | "next" | "2026-W41" | "2026-w41" | "2026W41"
def parse_date(text: str, *, today: date | None = None, week_start: WeekStart = "monday") -> date
    # "today" | "yesterday" | "mon".."sun" | "YYYY-MM-DD" | "MM-DD"
```

주차 라벨은 ISO 주차를 유지하고, `sunday` 모드는 범위만 하루 앞당긴다(일~토). `week_of`는 sunday 모드에서 일요일을 다음 ISO 주로 귀속시킨다.

**테스트 케이스**
- `Week.label`: (2026, 1) → `2026-W01`
- `start/end`: 2026-W40 → 09-28 ~ 10-04; sunday 모드 → 09-27 ~ 10-03
- 연말 경계: `week_of(2026-12-31)` → 2026-W53; `week_of(2027-01-01)` → 2026-W53; `week_of(2025-12-29)` → 2026-W01; `week_of(2021-01-03)` → 2020-W53
- `next/prev`: 2026-W53.next() → 2027-W01; 2026-W01.prev() → 2025-W52
- sunday 모드 귀속: `week_of(2026-09-27, "sunday")` → 2026-W40
- `contains`: 범위 양끝 포함, 범위 밖 False
- `days()` 길이 7, 첫째=start, 마지막=end
- `parse_week`: `this`/`last`/`next`(today=2026-10-01 기준 W40/W39/W41), `2026-W41`, `2026-w41`, `2026W41`, 잘못된 값(`2026-W54`, `2026-W00`, `W41`, `abc`) → InvalidInputError
- `parse_date` (today=2026-10-01 목): `today`→10-01, `yesterday`→09-30, `mon`→09-28, `thu`→10-01, `fri`→09-25(미래면 지난주), `sun`→09-27(monday 모드: 이번 주 일요일 10-04는 미래 → 지난주 09-27), `2026-10-01`, `10-01`→2026-10-01, `02-30`/`2026-13-01`/`foo` → InvalidInputError
- `parse_date` sunday 모드: today=2026-10-01, `sun` → 09-27 (이번 주 시작일)
- 커밋 `feat: add ISO week and date alias parsing`
