## 원인 (메인 세션 확인, 2026-10-19)

**A1 타이머 첫 취소 409**
- `web/pages/views.py`의 `timer_version`은 `timer.started_at.isoformat()`을 해시에 넣는다.
- 웹에서 시작하면 `services.start_timer(started_at=now)`의 `now`가 화면 시계(현지 시간대)라서 같은 세션 안의 값은 `…+09:00`이다. 시작 응답의 취소 버튼 버전은 이 값으로 만든다.
- 취소 요청은 DB에서 다시 읽는다. `UTCDateTime`이 UTC로 돌려주므로 값은 `…+00:00`이다. 같은 순간인데 문자열이 달라 버전이 다르다.
- 경과 갱신(`/timer/elapsed`)은 경과 글자만 바꾸고 버전은 바꾸지 않는다. 그래서 60초 뒤의 첫 취소도 409다.
- Windows 재현(TestClient, 임시 DB): 시작 응답 버전 f4dfcd7eca7c3ecc로 취소 → 409. 패널을 다시 불러온 버전은 e626ca9ae9586d62이고, 이 버전으로 취소 → 200.
- 기존 테스트가 놓친 까닭: 버전을 `GET /timer`(DB에서 읽은 값)에서 가져왔다.
- 다른 시각(기록 생성, 태스크 수정·완료·중단)은 모델 기본값 `utcnow()`라 같은 문제가 없다.

**A2 뒤로 가기 뒤 선택 상자 불일치**
- htmx는 주소를 바꾸기 전에 페이지 HTML(`body` innerHTML)을 기록 캐시(기본 10개, sessionStorage의 `htmx-history-cache`)에 저장한다. 뒤로 가기 하면 그 HTML을 되돌린다.
- 사용자가 고른 `select` 값은 HTML 속성(`selected`)에 남지 않는다. 그래서 되돌린 HTML의 표는 필터된 채이고 선택 상자는 서버가 처음 그린 값("전체")이다.
- `hx-push-url`을 쓰는 화면은 셋이다. 기록 필터·주 이동(`log_filters.html`, `week_nav.html`), 보고서 주 이동(`report_nav.html`), 태스크 필터(`task_filters.html`).
- `web/htmx.py`의 `is_htmx`는 이미 `HX-History-Restore-Request`에 전체 페이지를 준다. 캐시를 끄면 htmx가 이 헤더로 서버에 다시 요청하고, 서버가 주소의 값으로 `selected`까지 그린다.
- QA 세션 Windows 재현(Edge 헤드리스 + CDP, 2026-10-19):
  - payment → review → "이전 주"(실제 클릭) → 뒤로 → 앞으로 순서로 했다. 뒤로·앞으로 모두 URL·주차·표는 맞고 두 선택 상자만 "전체"였다.
  - 뒤로·앞으로 때 서버 요청은 없었다(캐시에서 복원). 캐시의 모든 항목 HTML에 payment·review의 `selected`가 없었다. 선택 상자가 `#log-table` 밖이라 첫 로드 마크업이 남는다.
  - 같은 URL을 직접 받으면 서버는 `selected`를 바르게 그린다.

**A4 끌어 놓은 뒤 CSP 경고**
- SortableJS는 끄는 동안 카드와 애니메이션 중인 형제 카드에 인라인 스타일(`transform`, `transition`)을 넣었다가 끝나면 비운다. 그래서 `style=""` 속성이 남는다.
- 상태 변경이 성공하면 htmx가 보드를 통째로 바꾼다. 이때 settle 단계가 같은 id의 옛 요소 속성(`attributesToSettle` 기본 `class`·`style`·`width`·`height`)을 새 요소에 `setAttribute`로 옮긴다. `style` 속성 쓰기가 CSP `style-src-attr` 위반으로 보고된다. 기능에는 영향이 없다.
- 이 앱은 인라인 `style`을 쓰지 않는다(CSP가 막는다). `style`을 settle에서 빼도 잃는 것이 없고, 끌어 놓기 말고 다른 경로에서 생길 같은 경고도 막는다.
- Phase 9 Task 9-4 확인에서 놓친 까닭: 메인 세션은 `onEnd`를 직접 불렀다. 그래서 SortableJS가 실제로 끌 때 넣는 인라인 스타일이 생기지 않았다.
- QA 세션 Windows 재현(Edge 헤드리스 + CDP 실제 HTML5 끌기, 2026-10-19):
  - 기본 설정에서 끌어 놓은 뒤(200) CSP 위반이 2건 났다. `style-src-attr`, 샘플은 빈 문자열, 위치는 `htmx-2.0.11.min.js:1:10457`, 대상은 형제 카드 `LI#task-1`·`LI#task-2`다.
  - 프로젝트 필터만 바꿔 보드를 다시 그리면 0건이다.
  - 페이지 안에서 `attributesToSettle`을 `["class","width","height"]`로 바꾸고 같은 끌기를 하면 0건이다(F3 근거).
  - 목록 `ul`에도 높이 고정을 푼 뒤 `style=""`가 남지만 id가 없어 settle이 옮기지 않는다.
